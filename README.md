# آتش و نمک: سایت رستوران زنجیره‌ای

سایت چندشعبه‌ای یک رستوران ایرانی: صفحهٔ اصلی با تیتر اختصاصی، منوی قابل
فیلتر، شش شعبه در تهران به همراه نقشه و ساعت کاری، رزرو میز سه‌مرحله‌ای،
«رزروهای من» با امکان لغو، رویدادها با رزرو صندلی، درخواست مهمانی خصوصی،
کارت هدیه، همکاری و تماس. ساخته‌شده با Vite + React 19 + Tailwind 4 و یک
Worker روی Hono برای مسیرهای فرم‌ها.

```sh
bun install
bun run dev        # http://localhost:5309
bun run typecheck
bun run build
```

## ساختار پروژه

| چه چیزی | فایل |
| --- | --- |
| همهٔ متن‌ها، قیمت‌ها، شعبه‌ها، آیتم‌های منو، رویدادها و موقعیت‌های شغلی | `src/content.ts` |
| عکس‌ها (یک مسیر برای هر عکس) | `PHOTOS` در `src/content.ts` و فایل‌ها در `public/images/` |
| رنگ، فونت، شعاع گوشه، سایه و توکن‌های حرکت | `src/styles.css` (`@theme`) |
| کامپوننت‌ها (دکمه، فیلد، چیپ، کارت، مودال، کشو، توست…) | `src/components/` |
| صفحه‌ها | `src/pages/` |
| اعتبارسنجی مشترک فرم‌ها و Worker | `src/shared/validation.ts` |
| دفتر رزرو نمایشی (تولید بازه‌های زمانی) | `src/shared/availability.ts` |
| مسیرهای Worker | `src/worker/index.ts` |

راهنمای زندهٔ استایل در **`/styleguide`** است (از فوتر هم لینک شده): نمونهٔ
رنگ‌ها، مقیاس تایپوگرافی، فاصله‌ها، شعاع گوشه‌ها، سایه‌ها، حرکت با دکمهٔ
پخش دوباره و همهٔ کامپوننت‌ها در حالت‌های مختلف.

## عکس‌ها

همهٔ عکس‌ها تصویر جایگزین تولیدشده‌اند و از طریق `PHOTOS` در `src/content.ts`
مسیردهی می‌شوند. برای استفاده از عکس خودتان، فایل را در `public/images/`
بگذارید و مسیر همان کلید را عوض کنید؛ چیز دیگری لازم نیست.

## صفحه‌ها

`/` خانه، `/menu` منو، `/locations` شعبه‌ها، `/locations/:slug` صفحهٔ هر شعبه،
`/reservations` رزرو، `/bookings` رزروهای من، `/events` رویدادها (با
`#private-dining`)، `/about` دربارهٔ ما، `/gift-cards` کارت هدیه،
`/careers` همکاری، `/contact` تماس، `/styleguide` و صفحهٔ ۴۰۴.

## داده‌ها و Worker

پایگاه داده‌ای وجود ندارد. رزروها و صندلی‌های رویداد در مرورگر ذخیره
می‌شوند (کلید `localStorage` با نام `atashonamak:bookings`)، همان‌طور وضعیت
شعبهٔ انتخابی منو و خبرنامه. همهٔ فرم‌ها JSON را به Worker می‌فرستند؛ Worker
با همان قواعد مرورگر اعتبارسنجی می‌کند و در صورت خطا `400` با خطاهای هر
فیلد، برای پر بودن بازه یا رویداد `409`، و در موفقیت `201` با کد پیگیری
برمی‌گرداند.

| مسیر | کاربرد |
| --- | --- |
| `GET /api/health` | `{ ok: true }` |
| `GET /api/availability?location&date&party[&after]` | بازه‌های یک روز (`open`، `closed` یا `full`) |
| `POST /api/reservations` | رزرو میز |
| `POST /api/event-bookings` | رزرو صندلی رویداد |
| `POST /api/private-dining` | درخواست مهمانی خصوصی |
| `POST /api/gift-cards` | کارت هدیه (نمایشی: پرداختی انجام نمی‌شود) |
| `POST /api/applications` | درخواست همکاری |
| `POST /api/contact` | فرم تماس |
| `POST /api/subscribe` | خبرنامه |

برای راه‌اندازی واقعی، `slotsFor` را با سیستم رزرو خودتان جایگزین کنید، پیش
از فروش کارت هدیه یا صندلی رویداد درگاه پرداخت را وصل کنید و هر فرم را در
`src/worker/index.ts` به ایمیل یا جدول D1 بفرستید.
